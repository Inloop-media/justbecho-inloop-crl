# JustBecho — Creative Reference Link

Social Content Direction — Vol. 01

Built by Inloop Media

---

A single-page moodboard / social content direction site for **JustBecho** — a verified
luxury-resale marketplace. Brand identity (gold monogram, charcoal + gold theme, Inter
typography) taken from the JustBecho brand guidelines; content pillars and reference links
supplied by Inloop Media.

- **Type:** Inter (display + body + labels)
- **Palette:** charcoal `#111827` ground, gold `#af8b3f` accent, clean white type
- **Pillars:** Becho Verified · The Luxury Find · JustBecho Knows · The Founder's Take · The Becho Community
- **Grid:** 11 reference pieces (reels, statics + carousels) with pillar filters and a lightbox gallery
